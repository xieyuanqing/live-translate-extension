# 流译 · YouTube 字幕、弹幕与评论翻译

[English](README.md) · [简体中文](README.zh-CN.md)

直播：抓取 YouTube 播放器的音频，可选 Gemini 3.5 或千问 3.8 LiveTranslate 实时翻译，字幕直接显示在播放器里，原声照常播放。
视频与回放：读取 YouTube 自带的字幕轨，用文字模型整片翻译并缓存在本机，翻好的部分立刻能看，再看同一视频不再花额度。
可选聊天翻译使用 Chrome 本地 Translator API；评论及展开的回复可用字幕文字模型按需翻译。
选中文字后右键，可调用现有文字模型翻译，或用微软 Neural / Gemini TTS 朗读日语和英语原文。

**开发版：0.4.0，尚未发布。** 本仓库是独立的 Chrome Manifest V3 扩展，界面目前为简体中文。暂时使用手动安装，尚未上架浏览器扩展商店。

设置页与插件弹窗共用浅色和柔和的中性灰深色主题。在「设置 → 通用 → 界面外观」选择跟随系统（默认）、浅色或深色，弹窗顶部也能一键切换。弹窗固定为 420 px 宽，保留圆角分组、蓝色主按钮和滑动开关；优先显示语言选择和翻译操作，连接状态与音量只在翻译运行时展示。

## 功能

**直播（音频实时翻译）**

- 字幕叠在播放器内，随全屏、剧场模式和窗口大小变化。
- 直播页可自动开始，也可以通过弹窗或 `Alt+T` 启停。
- 单独选择源语言和目标语言。实时翻译使用基础规则与本场背景/术语，不再选择通用、VTuber 等场景模板；已有场景偏好保留在整片字幕的高级设置。
- 可选注入标题、频道、简介，以及用户补充的背景资料，辅助识别人名和主题。
- 开播前可让已配置的文字模型把标题、简介整理成简短背景和最多 12 组候选术语。Gemini 把结果放进提示词；千问 3.8 只接收其协议支持的术语映射。该功能是实验性的，不能保证提高准确率。
- 弹窗展开「本场提示词与术语」，可查看和复制整理模型的输入、生成的背景/术语、冻结的 Gemini 提示词或千问翻译配置。可先点「生成并预览」，再开始翻译；输入未变时复用这份结果，不重复调用文字模型。开播前测试请先关闭自动开始，或停止当前翻译。术语优先保留主播名、有依据的读法和本场关键专名。
- 播放器暂停、静音或检测到广告时，暂停提交音频。
- 可在「设置 → 数据」开启本机直播日志：基础档记录连接状态和耗时，详细调试档还记录元数据、实际提示词、原文转写和译文片段；可按场或全部导出 JSON，便于复盘准确率。
- 已保存的详细日志可点「提示词」直接查看。本次新增日志还记录整理模型输入、播放器时间、千问输出编号、连接关闭原因及已发送/排队/丢弃音频块数量；采集数量不等于服务器已收到的数量。

**视频与回放（整片字幕翻译）**

- 读取视频自带的字幕轨：优先所选源语言的人工字幕，其次自动识别字幕；不使用 YouTube 自动翻译出来的字幕。
- 自动字幕先按词级时间重新切成完整语义单元再翻译，时间轴由程序保管，模型只处理编号和文字。
- 从当前播放位置开始翻，翻好一块就能看，然后继续往后、最后补前面；拖到没翻的地方会优先翻那里。
- 原文和译文按视频缓存在本机；再次打开自动显示，中途关页面回来可以续翻。
- 换了模型或提示词不会悄悄重翻：旧缓存照用并标注，点「重新翻译」才消耗额度。
- AI 整理与整片字幕翻译各自选择文字模型配置，均支持 OpenAI 兼容 chat/completions 和 Gemini generateContent；新增配置默认 OpenAI 兼容格式，模型名自填。

**YouTube 弹幕／聊天、评论及回复**

- 弹窗及「设置 → 弹幕与评论」提供两个独立开关，默认关闭；无需启动音频翻译或整片字幕翻译。
- 「译文样式」提供原样、文字颜色、下划线、点状线、虚线、波浪线、背景高亮、荧光笔、引用、边框、加粗、淡化共 12 种预设，支持装饰颜色与深浅色预览。评论和弹幕分别保存，默认原样；切换直接更新已有译文，不重新请求翻译，也不展开已收起的评论译文。
- 评论译文的基础字色跟随实际原文，操作按钮和提示按 YouTube 深浅主题保持可读；网页换主题只更新外观，不重新翻译。
- 聊天使用 Chrome 的 Translator API 在本机自动翻译可见的新文字消息，译文显示在原文下面。首次使用在 YouTube 聊天区点「准备本地翻译」准备语言包；源语言选自动检测时，还会使用本地 Language Detector。不支持的浏览器或语言组合会直接提示。
- 聊天译文紧跟原文，放在同一条消息正文里，沿用原文字号和颜色；付费留言和会员消息保留原来的底色。
- 纯表情（含频道图片表情）、纯数字刷屏，以及 `www`、`草`、`888888`、KAWAII、LOL、NT、NICE、GG 等短反应自动跳过，不进入翻译队列。兼容大小写、全角、标点和表情组合；正常句子里出现这些词仍会翻译。自定义图片表情的名称和鼠标悬停提示不当作正文翻译，原表情继续显示。
- 每条文字评论及展开的回复下面显示「翻译」按钮；「翻译当前可见评论」只翻译视口内已经加载的内容。使用「字幕翻译模型」，原文保留，译文按相同字号和行距直接接在下面，保留换行。译文放在 YouTube 折叠容器外，避免长评论被裁切；译文后的小文字按钮可重新翻译、收起或显示译文。「停止评论翻译」取消未完成请求。
- 评论请求可附带父评论、启用的视频背景及同页已整理的术语，不为评论额外调用 AI 整理。结果仅在当前页面内存里复用。

两种字幕模式共用同一个字幕层和设置。千问 3.8 自动识别源语言，使用所选目标语言，无法接收自由文本场景提示词。正在直播的页面用音频模式；普通视频和已结束的回放用整片字幕。转写模型（不依赖 YouTube 自动字幕）留到以后，前提是先解决整片音频从哪里来。

**划词翻译与日英朗读**

- 选中词语或句子，右键选择「流译：翻译与朗读」。句子旁的浮窗显示原文及译文，使用已配置的字幕文字模型和当前目标语言。点「播放原文」才朗读，打开浮窗不会自动出声。
- 只有日语和英语：忽略空格、数字、标点、表情后，纯拉丁字母读英语，其余读日语。例如 `Tokyo` 读英语，`東京` 读日语。不加入人名读音表或自定义发音。
- 默认微软，无需客户 API Key。日语默认 Nanami 女声，英语默认 Jenny 女声；「设置 → 朗读」可以分别选音色、调整慢／正常／快三档语速、试听日语和英语。消费者语音接口属于实验依赖，可能失效。
- 可切换 Gemini TTS，复用已有 Gemini Key 或单独填写，配置 TTS 模型和音色；自定义接口域名按需授权。模型初始为 `gemini-3.1-flash-tts-preview`，可以改为账号支持的新型号。免费额度以 AI Studio 项目实际限制为准。
- 浮窗支持停止、重播、换供应商、翻译和复制。关闭浮窗、页面导航或开始新朗读会停止旧任务，准备中的合成也能取消。重播复用短暂的内存音频。每次最多 4000 字；只在点击菜单后注入，帧受限时可在同一网页靠近该 iframe 显示，不打开额外页面或窗口。浏览器内部页可能禁止注入。

## 安装

1. 本开发版使用本地生成的 `live-translate-extension-0.4.0.zip`，或直接加载当前源码目录。[Releases](https://github.com/xieyuanqing/live-translate-extension/releases/latest) 提供已发布版本，0.4.0 暂未上传。
2. 解压到一个固定目录，安装后保留该目录。
3. 打开 `chrome://extensions/`，开启「开发者模式」。
4. 点「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
5. 刷新已经打开的 YouTube 页面。

也可以克隆本仓库，直接加载仓库根目录。使用插件不需要安装 Node.js、Android 工具，也没有编译步骤。

更新时，用新版文件替换**同一个安装目录**中的文件，在扩展管理页重新加载，再刷新 YouTube。不同的解压目录或商店安装可能对应不同的扩展 ID，本地设置不会自动迁移。

## 首次配置

1. 打开插件弹窗 →「设置」→「实时翻译」。默认保持 Gemini 3.5，填写自己的 [Google AI Studio Key](https://aistudio.google.com/apikey)；或切换到千问 3.8，填写百炼业务空间域名与 API Key，再点「授权千问连接」。千问 WebSocket 需要认证请求头，Chrome 会询问可选的「所有网站」权限；插件只对当前 YouTube 标签页的准确千问地址建立临时握手规则，连接成功后立即移除。
2. 确认浏览器能连接所选服务。Gemini 可在设置里配置 WSS 反代；千问目前只接受指定格式的百炼业务空间域名。
3. 选择翻译方向，默认是日语 → 中文。
4. 在「文字模型」里配置接口：新增配置默认 OpenAI 兼容 chat/completions，填写接口基础地址（通常以 `/v1` 结尾）、Key 和模型名。分别选「AI 整理模型」与「字幕翻译模型」；可复制配置后填不同模型名，让整理用小模型、字幕用强模型。已有配置保留原来的接口类型，Gemini 文字接口不单独填 Key 就复用 Gemini Live Key。模型名默认留空，点「列出可用模型」从你的账号里选。「测试连接」只查模型信息、不花额度，通过不代表生成一定可用；「生成测试」按翻译路径发一条极短请求，消耗少量额度。
5. 打开直播页。所选模型配置 Key 后默认自动开始，可在设置中关闭。要启用开播前的术语整理，还需配置可用的「文字模型」接口并开启标题、简介背景。
6. 可选在「弹幕与评论」开启任一功能。聊天按提示在 YouTube 聊天区准备本地翻译；评论先选好可用的字幕文字模型，再点击评论下的翻译按钮。
7. 要朗读，打开「朗读」试听日语和英语。微软无需客户 Key；Gemini 需要能访问所选 TTS 型号的 Gemini Key。

直播默认使用 `gemini-3.5-live-translate-preview`，切换后使用 `qwen3.8-livetranslate-flash-realtime`。可用性和费用取决于各自服务账号，安装插件不包含 API 额度。开播背景整理每次额外调用一次独立选定的文字模型，默认最多等待 60 秒，在「实时翻译 → AI 整理」可选 30／60／120 秒，包含连接、模型等待和完整回答；匹配的开播预览可直接复用，不重复调用。失败时 Gemini 使用基础提示词，千问不带自动生成的术语继续开始。

## 日常使用

| 操作 | 作用 |
| --- | --- |
| 开始 / 停止实时翻译，或 `Alt+T` | 控制当前标签页的音频翻译，原声继续播放 |
| 翻译整片字幕 | 非直播视频页显示；读取字幕轨、按当前位置优先翻译并缓存 |
| 取消翻译 / 隐藏字幕 / 重新翻译 | 取消只丢正在进行的请求，已翻好的块保留；隐藏不删缓存；重新翻译会再次消耗额度 |
| 听什么 / 翻译成 | 独立选择源语言和目标语言，字幕、聊天及评论共用 |
| 聊天翻译 / 评论翻译 | 独立开关；聊天自动翻译，评论按需翻译 |
| 翻译当前可见评论 / 停止评论翻译 | 翻译视口内已加载的评论，或取消未完成的评论请求 |
| 右键 → 翻译与朗读 | 句子旁显示原文和译文，点播放读日语／英语原文 |
| 设置 → 朗读 | 选择微软／Gemini、音色、模型、Key、默认语速，并试听 |
| 本场提示词与术语 | 合并本场补充、AI 整理与实际提示词/千问词表查看 |
| 本场补充 | 在上述区域补人名、当前游戏、活动等信息，或供千问词表整理；换视频或刷新后清空 |
| 应用当前设置并重新开始 | 实时翻译应用更新的语言、背景与术语 |
| 设置 → 整片字幕 → 高级 | 管理仅用于整片字幕的可复用场景提示词 |
| 设置 → 字幕外观 | 显示模式（双语 / 仅译文 / 仅原文）、译文位置、字号、位置、背景、字体、颜色即时生效，带真实预览 |
| 设置 → 数据 | 开启、导出或删除直播诊断日志；管理整片字幕缓存、设置备份与恢复默认 |

开始时冻结本场配置，断线重连和定时轮换继续使用同一份快照。运行中修改翻译相关设置，要重新开始才生效。临时补充输入后立即传到页面内存，关掉弹窗不会丢字。

整片字幕翻译时，播放器左上角显示进度和「从当前位置起可看到哪里」。关闭弹窗不影响任务；换视频、刷新或关闭标签页会取消尚未完成的请求，已完成的块已经落盘，回来再点「继续翻译」即可。

完整缓存无需 API Key 也能加载。弹窗会显示缓存实际使用的目标语言；配置变化时，完整和部分缓存都会保留，恢复原设置可继续翻译，或手动选择按新设置重新翻译。单次请求最多等待两分钟，超时后按重试规则处理。录播页会收起未运行的实时翻译统计，让弹窗更紧凑。

场景提示词是整片字幕的可复用偏好。实时 Gemini 使用基础翻译规则加本场整理结果，或未整理时的原始背景；千问接收目标语言和词表。长期背景和本场补充也可作为 AI 整理的输入，本场补充只属于当前视频。

## 数据与凭据

没有项目方运营的后端，**音频、字幕和评论的模型请求会使用云端服务**：直播音频发送给所选的 Gemini 或千问服务；字幕原文及启用的背景资料发送给配置的文字模型接口，也可能经过你配置的反代。启用开播背景整理时，标题、简介和补充资料会在开播前额外发送给文字模型一次；Gemini 再接收整理后的背景，千问只接收术语映射。

聊天由 Chrome 本地翻译，插件不把聊天文字发送到文字模型接口；Chrome 可能下载模型和语言包。评论翻译会把选中的评论、回复对应的父评论及启用的背景／术语发送给字幕翻译模型。聊天与评论译文只保留在页面内存里，不写入整片字幕缓存或直播日志。

划词翻译把选中的原文发送到字幕文字模型接口；点播放时把原文发送到所选微软／Gemini 语音服务。原文与译文保留在页面内存，后台最多暂存三段合成音频，重播缓存十分钟内有效，默认不保存音频文件。Gemini TTS Key 同样明文存在本机；设置导出默认剔除，只有明确勾选包含 Key 才导出。朗读用扩展独立播放器，不改 YouTube 的音频连接。

API Key、设置、场景与长期背景存在 `chrome.storage.local`，Key 当前**没有应用层加密**。默认不记录直播日志，本场补充和实时翻译字幕只在页面内存中；开启详细调试后，元数据、补充资料、提示词、原文与译文会持久写入本机扩展存储，直至删除或超过保留上限。基础档不保存语音文字和提示词。日志不保存原始音频，会遮盖已配置的 API Key；分享导出文件前仍请自行检查。每场最多 3000 条事件，只保留最近 20 场已结束日志。**整片字幕的原文与译文会持久保存在本机的扩展存储里**，不会自动过期，可在设置页删除。

使用自己的 Key，并在信任的电脑上使用。不要把 Key 写进源码、Issue、截图或安装包。自定义反代和第三方接口会接收经由它的请求，包括 API Key。上游对提交内容的处理依各自服务条款而定，本项目不能承诺上游永不保留数据。

商店分发、首次使用同意流程和正式隐私披露留到后续单独处理。

## 排查与限制

| 现象 | 建议 |
| --- | --- |
| 页面尚未连接 | 安装或更新后刷新 YouTube；弹窗提供刷新按钮 |
| 无法连接 Gemini | 检查 Key、模型权限、网络与反代地址 |
| 无法连接千问 | 检查业务空间域名、Key、「授权千问连接」权限与网络；本插件的千问模式暂不支持繁体中文作为目标语言 |
| 连接正常但没有字幕 | 确认正在播放语音、播放器未静音，观察输入音量；静音时没有译文是正常的 |
| 提示没有字幕轨 | 视频本身没有字幕，或自动字幕还没生成；把「听什么」改成自动检测可放宽轨道选择 |
| 提示字幕接口没有返回可用内容 | YouTube 的字幕接口需要播放器自己的校验参数。错误里会列出试过的路径，在内容脚本的控制台跑 `await LT.debug.probeCaptions()` 可看完整记录；先在播放器里手动开一次 CC 再试，仍不行可能是接口变了 |
| 文字模型报 404 / 401 | 检查模型名、接口地址是否到 `/v1`、Key 是否有该模型权限 |
| 第三方接口报跨域或后台未授权 | 在设置页点「授权浏览器访问该域名」，请求会改由扩展后台转发 |
| 聊天提示准备语言包或不支持本地接口 | 在聊天区点「准备本地翻译」，使用支持 Translator 的桌面版 Chrome；选择具体源语言可免用 Language Detector |
| 看不到评论翻译按钮，或没有可见评论可翻译 | 开启评论翻译，滚到评论区并展开需要的回复；插件不抓取尚未加载的评论 |
| 朗读失败或没有声音 | 在「朗读」试听日语／英语，检查浏览器音量和网络；Gemini 还需检查 Key、TTS 模型与域名授权，可手动换供应商 |
| 与 YouTube CC 重叠 | 关闭原生 CC，或调整字幕距底部的位置 |
| 显示兼容音频模式 | AudioWorklet 不可用时已退回 ScriptProcessor，页面繁忙可能影响采集 |

Gemini 默认每 505 秒轮换连接，千问每 120 秒轮换；断线会重连，短暂显示切换连接属于正常过程。反馈问题时提供 Chrome 版本、插件版本和复现步骤，日志先去除 Key 和私人背景。

- Chrome 是已测试浏览器，其他 Chromium 浏览器及其商店尚未验证。
- 0.4.0 测试包还加入划词翻译、日英朗读。语法、自检、模拟回归和宽／窄屏检查已通过；微软日语／英语真实合成及扩展播放已在独立 Chromium 配置中验证。Gemini 请求／播放和划词翻译使用网络替身验证，真实 Gemini TTS 权限与音色听感尚未验证。评论／聊天检查仍使用模拟 YouTube DOM 和模型结果；当前 YouTube 兼容性、Chrome 语言包下载及真实模型翻译待用户实测。
- 快速聊天可能超过本地翻译速度：最多排队 30 条，优先仍可见的文字消息，过时消息会跳过；纯表情和超过 2000 字的消息跳过。评论每批最多 8 条、6000 原文字数；一批失败后停止后续请求，解决问题后手动重试。
- 标准画中画不显示本扩展的 DOM 字幕层。
- 实时翻译会有延迟、漏译和专名错误，目标是辅助理解。
- 自动生成的背景和术语只是从元数据推断的候选线索，不等于已识别的实际说话内容。此前短样本里，自动生成提示词没有稳定提高准确率；千问实时协议只支持术语映射、不接收自由文本提示词，重复口癖在实验中还触发过服务端中断。
- 整片字幕的原文来自 YouTube 字幕轨：自动字幕已经听错的内容，翻译阶段只能按上下文尽量补救，不能保证纠正。
- 字幕轨读取依赖 YouTube 未公开的接口与播放器行为，服务端变更可能导致读取失败。
- 当前 preview 模型和项目实测的 `systemInstruction` 行为属于实验依赖，后续服务变更可能影响效果。
- 提示词围栏是尽力约束，不能保证模型绝不执行资料里的指令。
- 跨多次轮换的长时间真实直播，以及整片字幕在真实浏览器里的端到端验证，仍需专门测试。

## 开发

Node.js 22+，无需安装 npm 依赖：

```sh
npm run check
npm run package
```

`check` 包括语法检查、版本一致性、算法自检（含 json3 解析、分句、分块校验、播放调度）、会话竞态、直播日志脱敏与轮换、千问协议/认证、整片字幕任务，以及划词／朗读的取消、语种、音频格式和资源清理回归。`package` 生成 `dist/live-translate-extension-0.4.0.zip`，只包含运行文件，`manifest.json` 直接位于 ZIP 根目录。GitHub Actions 执行同样的检查与打包验证。

自动化测试使用模拟回调、WebSocket、字幕轨与模型响应，不能代替真实浏览器与模型实测。代码结构和关键约束见 [开发说明](docs/development.md)。
