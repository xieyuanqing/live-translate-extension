# 流译 · YouTube 字幕、聊天与评论翻译

[English](README.md) · [简体中文](README.zh-CN.md)

直播：抓取 YouTube 播放器的音频，可选 Gemini 3.5 或千问 3.8 LiveTranslate 实时翻译，字幕直接显示在播放器里，原声照常播放。
视频与回放：读取 YouTube 自带的字幕轨，用文字模型整片翻译并缓存在本机，翻好的部分立刻能看，再看同一视频不再花额度。
可选聊天翻译使用 Chrome 本地 Translator API；评论及展开的回复可用独立选择的文字接口按需翻译。
选中文字后右键，可调用现有文字模型翻译，或用微软 Neural / Gemini TTS 朗读日语和英语原文。

**开发版：0.4.5，尚未发布。** 本仓库是独立的 Chrome Manifest V3 扩展，界面目前为简体中文。暂时使用手动安装，尚未上架浏览器扩展商店。

设置页与插件弹窗共用浅色和柔和的中性灰深色主题。在「设置 → 外观」选择跟随系统（默认）、浅色或深色，弹窗顶部也能一键切换。弹窗固定为 420 px 宽，保留圆角分组、蓝色主按钮和滑动开关；优先显示语言选择和翻译操作，连接状态与音量只在翻译运行时展示。

「设置 → 接口」集中配置文字、直播和语音的地址、Key、模型名与浏览器授权。功能页各自用下拉选择接口：AI 整理、整片字幕、划词和评论独立保存；旧评论配置首次沿用字幕接口，后续分别选择。编辑接口不会改变功能选用。

| 分组 | 设置页 |
| --- | --- |
| 开始 | 接口 · 语言与背景 |
| 功能 | 实时翻译 · 整片字幕 · 聊天与评论 · 划词与朗读 |
| 外观与数据 | 外观 · 数据与备份 · 高级与关于 |

「外观」集中界面主题，并分字幕、评论、聊天三个标签；提示词预览、诊断日志和开发者命令收进「高级与关于」，默认折叠。窄屏导航和文字接口列表使用下拉框。配置引导区分缺少填写、尚需授权，以及当前设置页会话内对同一套配置的生成测试通过；填好 Key 不等于账号已经验证。

## 功能

**直播（音频实时翻译）**

- 字幕叠在播放器内，随全屏、剧场模式和窗口大小变化。
- YouTube 播放器底部控制栏只保留一个与周围控件大小相近的灰白「流译」图标，点击启停实时翻译。直播字幕显隐放在扩展弹窗；隐藏只影响画面，仍会采集音频并调用模型。
- 直播页可自动开始，也可以通过弹窗或 `Alt+T` 启停。
- 单独选择源语言和目标语言。实时翻译使用基础规则与本场背景/术语；可复用翻译偏好保留在「整片字幕 → 翻译偏好」。
- 可选注入标题、频道、简介，以及用户补充的背景资料，辅助识别人名和主题。
- 开播前可让已配置的文字模型把标题、简介整理成简短背景和最多 12 组候选术语。Gemini 把结果放进提示词；千问 3.8 只接收其协议支持的术语映射。该功能是实验性的，不能保证提高准确率。
- 弹窗展开「本场提示词与术语」，可查看和复制整理模型的输入、生成的背景/术语、冻结的 Gemini 提示词或千问翻译配置。可先点「生成并预览」，再开始翻译；输入未变时复用这份结果，不重复调用文字模型。开播前测试请先关闭自动开始，或停止当前翻译。术语优先保留主播名、有依据的读法和本场关键专名。
- 播放器暂停、静音或检测到广告时，暂停提交音频。
- 可在「设置 → 高级与关于」开启本机直播日志：基础档记录连接状态和耗时，详细调试档还记录元数据、实际提示词、原文转写和译文片段；可按场或全部导出 JSON，便于复盘准确率。
- 已保存的详细日志可点「提示词」直接查看。本次新增日志还记录整理模型输入、播放器时间、千问输出编号、连接关闭原因及已发送/排队/丢弃音频块数量；采集数量不等于服务器已收到的数量。

**视频与回放（整片字幕翻译）**

- 读取视频自带的字幕轨：优先所选源语言的人工字幕，其次自动识别字幕；不使用 YouTube 自动翻译出来的字幕。
- 自动字幕先按词级时间重新切成完整语义单元再翻译，时间轴由程序保管，模型只处理编号和文字。
- 从当前播放位置开始翻，翻好一块就能看，然后继续往后、最后补前面；拖到没翻的地方会优先翻那里。
- 原文和译文按视频缓存在本机；再次打开自动显示，中途关页面回来可以续翻。
- 普通视频和已结束回放可点播放器里的单个图标开始／取消整片翻译；翻译完成后，同一图标用于显示／隐藏已缓存字幕。弹窗也能控制显隐；隐藏不会删除缓存。
- 换了模型或提示词不会悄悄重翻：旧缓存照用并标注，点「重新翻译」才消耗额度。
- AI 整理与整片字幕翻译各自选择文字接口，均支持 OpenAI 兼容 chat/completions 和 Gemini generateContent；新增配置默认 OpenAI 兼容格式，模型名自填。

**YouTube 弹幕／聊天、评论及回复**

- 弹窗及「设置 → 聊天与评论」提供两个独立开关，默认关闭；无需启动音频翻译或整片字幕翻译。
- 「设置 → 外观 → 评论／聊天」提供原样、文字颜色、下划线、点状线、虚线、波浪线、背景高亮、荧光笔、引用、边框、加粗、淡化共 12 种预设，支持装饰颜色与深浅色预览。评论和聊天分别保存，默认原样；切换直接更新已有译文，不重新请求翻译，也不展开已收起的评论译文。
- 评论译文的基础字色跟随实际原文，操作按钮和提示按 YouTube 深浅主题保持可读；网页换主题只更新外观，不重新翻译。
- 聊天使用 Chrome 的 Translator API 在本机自动翻译可见的新文字消息，译文显示在原文下面。首次使用在扩展弹窗点「准备本地翻译」准备语言包；源语言选自动检测时，还会使用本地 Language Detector。不支持的浏览器或语言组合会直接提示。聊天控制和状态只在扩展弹窗，不占用 YouTube 聊天区顶部。
- 聊天译文紧跟原文，放在同一条消息正文里，沿用原文字号和颜色；付费留言和会员消息保留原来的底色。
- 纯表情（含频道图片表情）、纯数字刷屏，以及 `www`、`草`、`888888`、KAWAII、LOL、NT、NICE、GG 等短反应自动跳过，不进入翻译队列。兼容大小写、全角、标点和表情组合；正常句子里出现这些词仍会翻译。自定义图片表情的名称和鼠标悬停提示不当作正文翻译，原表情继续显示。
- 每条文字评论及展开的回复下面显示「翻译」按钮；「翻译当前可见评论」只翻译视口内已经加载的内容。使用「聊天与评论」里选定的接口，原文保留，译文按相同字号和行距直接接在下面，保留换行。译文放在 YouTube 折叠容器外，避免长评论被裁切；译文后的小文字按钮可重新翻译、收起或显示译文。「停止评论翻译」取消未完成请求。
- 评论请求可附带父评论、启用的视频背景及同页已整理的术语，不为评论额外调用 AI 整理。结果仅在当前页面内存里复用。

两种字幕模式共用同一个字幕层和设置。千问 3.8 自动识别源语言，使用所选目标语言，无法接收自由文本提示词。正在直播的页面用音频模式；普通视频和已结束的回放用整片字幕。转写模型（不依赖 YouTube 自动字幕）留到以后，前提是先解决整片音频从哪里来。

**划词翻译与日英朗读**

- 选中词语或句子，右键选择「流译：翻译与朗读」。句子旁的浮窗显示原文及译文；划词翻译独立选择文字模型配置，沿用当前目标语言。点原文旁的扬声器才朗读，打开浮窗不会自动出声。
- 只有日语和英语：忽略空格、数字、标点、表情后，纯拉丁字母读英语，其余读日语。例如 `Tokyo` 读英语，`東京` 读日语。不加入人名读音表或自定义发音。
- 默认微软，无需客户 API Key。日语默认 Nanami 女声，英语默认 Jenny 女声；「设置 → 划词与朗读」可以分别选音色、调整慢／正常／快三档语速、试听日语和英语。消费者语音接口属于实验依赖，可能失效。
- 可切换 Gemini TTS，复用已有 Gemini Key 或单独填写，配置 TTS 模型和音色；自定义接口域名按需授权。模型初始为 `gemini-3.1-flash-tts-preview`，可以改为账号支持的新型号。免费额度以 AI Studio 项目实际限制为准。
- 浮窗可分别切换翻译模型与朗读接口；顶部也能切换目标语言。更换模型或目标语言会取消旧请求并重译，划词模型与字幕模型独立保存。原文旁的扬声器再次点击即停止；复制、重译只显示带提示的图标，译文卡片内直接显示“翻译中…”，切换朗读接口仅短暂提示。音色和语速在「设置 → 划词与朗读」调整，API Key、提示词与模型管理留在设置页。关闭浮窗、页面导航或开始新朗读会停止旧任务，准备中的合成也能取消。重播复用短暂的内存音频。每次最多 4000 字；只在点击菜单后注入，帧受限时可在同一网页靠近该 iframe 显示，不打开额外页面或窗口。浏览器内部页可能禁止注入。
- 原文超过五行默认折叠，可以展开；译文使用面板可用高度。按住标题栏拖动或点图钉可固定位置；取消固定后继续跟随选区，缩放窗口时会限制在可见范围内。

## 安装

1. 本开发版使用本地生成的 `live-translate-extension-0.4.5.zip`，或直接加载当前源码目录。[Releases](https://github.com/xieyuanqing/live-translate-extension/releases/latest) 提供已发布版本，0.4.5 暂未上传。
2. 解压到一个固定目录，安装后保留该目录。
3. 打开 `chrome://extensions/`，开启「开发者模式」。
4. 点「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
5. 刷新已经打开的 YouTube 页面。

也可以克隆本仓库，直接加载仓库根目录。使用插件不需要安装 Node.js、Android 工具，也没有编译步骤。

更新时，用新版文件替换**同一个安装目录**中的文件，在扩展管理页重新加载，再刷新 YouTube。不同的解压目录或商店安装可能对应不同的扩展 ID，本地设置不会自动迁移。

## 首次配置

先配想用的模式即可；直播音频与整片字幕不要求同时配好两套协议。

1. 打开扩展弹窗 →「设置」，在「语言与背景」选择源语言与目标语言，默认日语 → 中文。
2. 在「接口」配置一套接口。看直播：打开「直播翻译」，填写 Gemini Key，或千问百炼业务空间域名与 Key。看视频／回放：打开「文字翻译」，新增接口，填写地址、Key、模型名，在地址下授权域名，并运行「生成测试」。
3. 回「实时翻译」或「整片字幕」，用功能页的下拉框选用该接口。打开 YouTube，播放直播或带字幕的视频，点击弹窗或播放器里的流译按钮开始。直播在选定接口有 Key 后默认自动开始，可在「实时翻译」关闭。
4. 需要时再开附加功能。「实时翻译 → AI 整理」「聊天与评论」「划词与朗读」各自选择文字接口。聊天使用本地翻译，在弹窗点「准备本地翻译」下载语言包；微软朗读无需客户 Key，Gemini 朗读在「接口 → 语音朗读」配置，音色、语速和试听在「划词与朗读」调整。

Gemini Key 可在 [Google AI Studio](https://aistudio.google.com/apikey) 获取。Gemini 直播使用 WSS 地址；千问支持指定格式的百炼业务空间，并需点击常驻的「所有网站权限 → 授权」。这是认证请求头的要求；扩展只为当前 YouTube 标签页与准确千问地址建立临时握手规则，连接成功后移除。

文字接口支持 OpenAI 兼容协议及 Gemini。先选预设再点「新增接口」，即可填好协议与地址：DeepSeek、硅基流动、火山方舟、阿里百炼（北京／新加坡）、OpenRouter、Groq、月之暗面、OpenAI、Gemini；其他服务选「自定义接口」。预设新增独立配置，保留原有凭据和各功能选用。Gemini 文字接口不单独填 Key 时仍复用 Gemini 直播 Key。

模型可以直接手填，也可以点「获取模型」。右侧箭头展开全部返回的模型，输入文字才筛选，方向键和回车也能选择；接口不提供模型列表时仍可手填。「查询接口」只查信息，通过不代表生成可用；「生成测试」按翻译路径发一条极短请求并消耗少量额度。拒绝浏览器授权会取消请求。

「自定义请求头」按名称和值填写，例如 `X-Api-Key`、`Authorization`、`X-Tenant`。模型列表、查询、生成测试、背景整理、整片字幕、评论和划词翻译都会携带，也支持后台转发；名称不区分大小写，同名项覆盖默认头，可以只用请求头鉴权。这些设置仅用于文字接口。新增的「聊天翻译」标签保留 Chrome 本地翻译；候选服务折叠显示并标明「暂未接入」，不能选用。地址和范围见[接口预设说明](docs/interface-presets.md)。

直播默认使用 `gemini-3.5-live-translate-preview`，切换后使用 `qwen3.8-livetranslate-flash-realtime`。可用性和费用取决于各自服务账号，安装插件不包含 API 额度。开播背景整理每次额外调用一次独立选定的文字模型，默认最多等待 60 秒，在「实时翻译 → AI 整理」可选 30／60／120 秒，包含连接、模型等待和完整回答；匹配的开播预览可直接复用，不重复调用。失败时 Gemini 使用基础提示词，千问不带自动生成的术语继续开始。

## 日常使用

| 操作 | 作用 |
| --- | --- |
| 开始 / 停止实时翻译，或 `Alt+T` | 控制当前标签页的音频翻译，原声继续播放 |
| 翻译整片字幕 | 非直播视频页显示；读取字幕轨、按当前位置优先翻译并缓存 |
| 取消翻译 / 隐藏字幕 / 重新翻译 | 取消只丢正在进行的请求，已翻好的块保留；隐藏不删缓存；重新翻译会再次消耗额度 |
| 听什么 / 翻译成 | 独立选择源语言和目标语言，字幕、聊天及评论共用 |
| 聊天翻译 / 评论翻译 | 独立开关；聊天自动翻译，评论按需翻译 |
| 翻译当前可见评论 / 停止评论翻译 | 翻译视口内已加载的评论，或取消未完成的评论请求 |
| 右键 → 翻译与朗读 | 句子旁显示原文和译文；可换翻译模型、朗读接口，点原文旁扬声器读日语／英语 |
| 设置 → 接口 | 配置地址、Key、模型及浏览器授权；各功能在自己的页面选择接口 |
| 设置 → 划词与朗读 | 分别选择划词翻译和朗读接口，调整音色、默认语速并试听 |
| 本场提示词与术语 | 合并本场补充、AI 整理与实际提示词/千问词表查看 |
| 本场补充 | 在上述区域补人名、当前游戏、活动等信息，或供千问词表整理；换视频或刷新后清空 |
| 应用当前设置并重新开始 | 实时翻译应用更新的语言、背景与术语 |
| 设置 → 整片字幕 → 翻译偏好 | 管理仅用于整片字幕的可复用提示词 |
| 设置 → 外观 | 选择界面主题，调整字幕、评论、聊天的外观；字幕带真实预览 |
| 设置 → 数据与备份 | 管理字幕缓存、备份与恢复默认；勾选保留接口时，保留三类接口的 Key、地址、可配置模型名与各功能选用 |
| 设置 → 高级与关于 | 查看提示词，导出或删除诊断日志，查看开发者命令与版本 |

开始时冻结本场配置，断线重连和定时轮换继续使用同一份快照。运行中修改翻译相关设置，要重新开始才生效。临时补充输入后立即传到页面内存，关掉弹窗不会丢字。

整片字幕翻译时，播放器左上角显示进度和「从当前位置起可看到哪里」。关闭弹窗不影响任务；换视频、刷新或关闭标签页会取消尚未完成的请求，已完成的块已经落盘，回来再点「继续翻译」即可。

完整缓存无需 API Key 也能加载。弹窗会显示缓存实际使用的目标语言；配置变化时，完整和部分缓存都会保留，恢复原设置可继续翻译，或手动选择按新设置重新翻译。单次请求最多等待两分钟，超时后按重试规则处理。录播页会收起未运行的实时翻译统计，让弹窗更紧凑。

翻译偏好是整片字幕的可复用提示词。实时 Gemini 使用基础翻译规则加本场整理结果，或未整理时的原始背景；千问接收目标语言和词表。长期背景和本场补充也可作为 AI 整理的输入，本场补充只属于当前视频。

## 数据与凭据

没有项目方运营的后端，**音频、字幕和评论的模型请求会使用云端服务**：直播音频发送给所选的 Gemini 或千问服务；字幕原文及启用的背景资料发送给配置的文字模型接口，也可能经过你配置的反代。启用开播背景整理时，标题、简介和补充资料会在开播前额外发送给文字模型一次；Gemini 再接收整理后的背景，千问只接收术语映射。

聊天由 Chrome 本地翻译，插件不把聊天文字发送到文字模型接口；Chrome 可能下载模型和语言包。评论翻译会把选中的评论、回复对应的父评论及启用的背景／术语发送给独立选择的评论接口。聊天与评论译文只保留在页面内存里，不写入整片字幕缓存或直播日志。

划词翻译把选中的原文发送到划词所选文字模型接口；点播放时把原文发送到所选微软／Gemini 语音服务。原文与译文保留在页面内存，后台最多暂存三段合成音频，重播缓存十分钟内有效，默认不保存音频文件。Gemini TTS Key 同样明文存在本机；设置导出默认剔除，只有明确勾选包含 Key 才导出。朗读用扩展独立播放器，不改 YouTube 的音频连接。

API Key、自定义请求头、设置、翻译偏好与长期背景存在 `chrome.storage.local`，Key 和请求头当前**没有应用层加密**。默认备份排除 Key 和请求头，导入这种备份会保留同一接口现有的凭据。默认不记录直播日志，本场补充和实时翻译字幕只在页面内存中；开启详细调试后，元数据、补充资料、提示词、原文与译文会持久写入本机扩展存储，直至删除或超过保留上限。基础档不保存语音文字和提示词。日志不保存原始音频，会遮盖已配置的 API Key；分享导出文件前仍请自行检查。每场最多 3000 条事件，只保留最近 20 场已结束日志。**整片字幕的原文与译文会持久保存在本机的扩展存储里**，不会自动过期，可在设置页删除。

使用自己的 Key，并在信任的电脑上使用。不要把 Key 写进源码、Issue、截图或安装包。自定义反代和第三方接口会接收经由它的请求，包括 API Key 和自定义请求头。上游对提交内容的处理依各自服务条款而定，本项目不能承诺上游永不保留数据。

商店分发、首次使用同意流程和正式隐私披露留到后续单独处理。

## 排查与限制

| 现象 | 建议 |
| --- | --- |
| 页面尚未连接 | 安装或更新后刷新 YouTube；弹窗提供刷新按钮 |
| 无法连接 Gemini | 检查 Key、模型权限、网络与反代地址 |
| 无法连接千问 | 检查业务空间域名、Key、「所有网站权限 → 授权」权限与网络；本插件的千问模式暂不支持繁体中文作为目标语言 |
| 连接正常但没有字幕 | 确认正在播放语音、播放器未静音，观察输入音量；静音时没有译文是正常的 |
| 提示没有字幕轨 | 视频本身没有字幕，或自动字幕还没生成；把「听什么」改成自动检测可放宽轨道选择 |
| 提示字幕接口没有返回可用内容 | YouTube 的字幕接口需要播放器自己的校验参数。错误里会列出试过的路径，在内容脚本的控制台跑 `await LT.debug.probeCaptions()` 可看完整记录；先在播放器里手动开一次 CC 再试，仍不行可能是接口变了 |
| 文字模型报 404 / 401 | 检查模型名、接口地址是否与服务文档一致、Key 是否有该模型权限 |
| 第三方接口报跨域或后台未授权 | 在接口地址下点「授权」，请求可改由后台转发；含端口的本地网关也按域名匹配权限，请求仍保留端口 |
| 聊天提示准备语言包或不支持本地接口 | 在扩展弹窗点「准备本地翻译」，使用支持 Translator 的桌面版 Chrome；选择具体源语言可免用 Language Detector |
| 看不到评论翻译按钮，或没有可见评论可翻译 | 开启评论翻译，滚到评论区并展开需要的回复；插件不抓取尚未加载的评论 |
| 朗读失败或没有声音 | 在「划词与朗读」试听日语／英语，检查浏览器音量和网络；Gemini 还需检查 Key、TTS 模型与域名授权，可手动换接口 |
| 与 YouTube CC 重叠 | 关闭原生 CC，或调整字幕距底部的位置 |
| 显示兼容音频模式 | AudioWorklet 不可用时已退回 ScriptProcessor，页面繁忙可能影响采集 |

Gemini 默认每 505 秒轮换连接，千问每 120 秒轮换；断线会重连，短暂显示切换连接属于正常过程。反馈问题时提供 Chrome 版本、插件版本和复现步骤，日志先去除 Key 和私人背景。

- Chrome 是已测试浏览器，其他 Chromium 浏览器及其商店尚未验证。
- 0.4.5 接口更新通过语法、自检与 155 项模拟回归。隔离 Chromium 覆盖 1440／390 px 深浅主题，检查模型完整列表、筛选、键盘及手填、请求头编辑和保存、预设、占位，无横向溢出或脚本错误；权限和上游接口使用替身，不代表真实账号已经验证。
- 0.4.4 设置改版通过 66 个 JavaScript 文件语法检查、自检和全部 144 项模拟回归；隔离 Chromium 内存页面检查了九个设置页、独立功能选用、拒绝权限、过期测试结果、外观三个标签，并覆盖 1440／1024／390 px 的深浅主题，无脚本错误或横向溢出。两套示例接口、高级折叠并显示首次引导时，390 px 文字接口页高 1413 px，早期截图为 2314 px。权限与模型使用替身；Chrome 原生授权弹窗、真实账号和当前 YouTube 流程仍待实测。
- 0.4.2 测试包通过语法、自检和 121 项模拟回归。隔离 Chromium 页面验证了单个播放器图标、供应商与目标语言切换、简洁的朗读和加载状态、图钉、长文本展开及 390 px 浮窗布局。新版图标尚未在真实 YouTube 观看页核对。
- 此前 0.4.0 在真实 YouTube 观看页验证过旧版双按钮位于原生控制栏内；微软日语／英语真实合成及扩展播放也在独立 Chromium 配置中通过。Gemini 请求／播放和划词翻译使用网络替身验证；真实 Gemini TTS 权限与音色听感、Chrome 语言包下载以及真实 YouTube 直播／整片翻译操作仍待实测。
- 快速聊天可能超过本地翻译速度：最多排队 30 条，优先仍可见的文字消息，过时消息会跳过；纯表情和超过 2000 字的消息跳过。评论每批最多 8 条、6000 原文字数；一批失败后停止后续请求，解决问题后手动重试。
- 标准画中画不显示本扩展的 DOM 字幕层。
- 实时翻译会有延迟、漏译和专名错误，目标是辅助理解。
- 自动生成的背景和术语只是从元数据推断的候选线索，不等于已识别的实际说话内容。此前短样本里，自动生成提示词没有稳定提高准确率；千问实时协议只支持术语映射、不接收自由文本提示词，重复口癖在实验中还触发过服务端中断。
- 整片字幕的原文来自 YouTube 字幕轨：自动字幕已经听错的内容，翻译阶段只能按上下文尽量补救，不能保证纠正。
- 字幕轨读取依赖 YouTube 未公开的接口与播放器行为，服务端变更可能导致读取失败。
- 当前 preview 模型和项目实测的 `systemInstruction` 行为属于实验依赖，后续服务变更可能影响效果。
- 提示词围栏是尽力约束，不能保证模型绝不执行资料里的指令。
- 跨多次轮换的长时间真实直播，以及整片字幕在真实浏览器里的端到端验证，仍需专门测试。

## 开发

Node.js 22+，无需安装 npm 依赖：

```sh
npm run check
npm run package
```

`check` 包括语法检查、版本一致性、算法自检（含 json3 解析、分句、分块校验、播放调度）、会话竞态、直播日志脱敏与轮换、千问协议/认证、整片字幕任务，以及划词／朗读的取消、语种、音频格式和资源清理回归。`package` 生成 `dist/live-translate-extension-0.4.5.zip`，只包含运行文件，`manifest.json` 直接位于 ZIP 根目录。GitHub Actions 执行同样的检查与打包验证。

自动化测试使用模拟回调、WebSocket、字幕轨与模型响应，不能代替真实浏览器与模型实测。代码结构和关键约束见 [开发说明](docs/development.md)。
