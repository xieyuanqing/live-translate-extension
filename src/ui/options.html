了解整理流程与失败处理

每次开播额外请求一次，输入匹配时复用已生成的预览。等待时间包含连接、模型等待和完整回答，手动「生成并预览」也使用此上限。Gemini 文字接口的空白 Key 只复用 Gemini 直播 Key；整理失败时，Gemini 按原资料开始，千问不带自动术语开始。

YouTube 聊天

自动翻译新文字消息，在原文下面显示译文。

本地翻译无需 API Key；在 YouTube 页打开流译弹窗，点击「准备本地翻译」下载语言包。

了解本地翻译

使用「语言与背景」的语言方向；保留用户名、原文、表情及链接。首次使用需下载语言包，要求支持 Translator API 的桌面 Chrome；自动检测还需 Language Detector。不可用时提示原因，不会转为付费接口。消息在本机处理，队列最多 30 条，优先可见消息；跳过纯表情、数字刷屏、短反应和超过 2000 字的消息，页面内复用重复句结果。

了解评论翻译与数据处理

按需翻译单条或当前可见评论，结果放在原文下面；未加载评论不会被抓取，回复展开后才参与可见内容翻译。请求会消耗文字模型额度，可附带视频标题、简介、长期背景和同页已整理术语；回复附带父评论。每批最多 8 条，单条最长 6000 字；页面内复用结果，停止或换视频取消未完成请求。

为何需要所有网站权限

千问要求认证请求头，因此 Chrome 需要「所有网站」权限；扩展只对当前 YouTube 标签页和准确连接地址设置临时握手规则，连上后移除。播放器音频及术语映射发送到该接口。
