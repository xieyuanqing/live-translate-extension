                    查看 VPS 接口约定（GET /health · GET /api/models · POST /api/transcribe · GET /api/jobs/:id）
                    

                      
1. 健康检查：GET  /health
   Header: Authorization: Bearer <token>
   返回：{ "ok": true, "version": "1.0" }

2. 模型清单：GET  /api/models
   返回：{ "defaultModel": "gemini-3.5-transcribe",
            "models": [{ "id": "gemini-3.5-transcribe", "label": "Gemini 3.5 Transcribe",
                         "provider": "Google", "description": "..." }] }

3. 提交转写：POST /api/transcribe
   Body:  { "videoId": "...", "url": "https://www.youtube.com/watch?v=...",
            "sourceLang": "ja", "model": "", "context": "标题/人名提示" }
   返回：{ "jobId": "...", "status": "queued | done", "units": [...] }

4. 轮询结果：GET  /api/jobs/:jobId
   返回：{ "status": "downloading | transcribing | done | error",
            "progress": 65, "stage": "正在转写 5/8 段",
            "units": [{ "startMs": 1200, "endMs": 4500, "text": "原文句子" }],
            "error": "" }
