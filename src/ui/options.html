YouTube 弹幕／聊天

            
            
自动翻译聊天区的新文字消息，在原文下面显示译文。使用「语言与背景」里的源语言和目标语言，原文、用户名、表情及链接保留。

            
首次启用时，在 YouTube 聊天区点「准备本地翻译」下载所需语言包。需要支持 Translator API 的桌面版 Chrome；源语言选自动检测时，还需本地 Language Detector。不可用时直接提示，不会转为付费接口。

            
消息在本机翻译，不使用你的文字模型 Key。队列最多 30 条，优先仍可见的消息；纯表情、数字刷屏、www／草／LOL／GG 等短反应和超过 2000 字的消息跳过，重复句在当前页面复用结果。

          

          

            
YouTube 评论及回复

            
            
每条文字评论下显示「翻译」，评论区及弹窗另有「翻译当前可见评论」。只翻译已选择的内容，结果显示在原文下面；未加载的评论不会被抓取，回复只在展开后参与可见内容翻译。

            

              复用字幕翻译模型
              

              配置字幕翻译模型
            

            
调用会消耗文字模型额度。可附带视频标题、简介、长期背景及同页已整理的术语；翻译回复时附带父评论。每批最多 8 条，最长单条 6000 字；页面内复用已翻译结果，停止或换视频取消未完成请求。

          

        


        
        

          

            
文字模型

            

              AI 整理与整片字幕翻译分别选模型、独立保存。可复制一套接口配置后填写不同的模型名，分别用于整理和翻译；直播音频仍发送给「实时翻译」里选定的 Live 模型。
            

            
两者均支持 OpenAI 兼容格式（chat/completions），新增配置默认使用此格式。填写接口地址、API Key 和该服务实际支持的模型名即可；已有配置保留原来的接口类型。

直播诊断日志

            

              日志级别（下一场直播起生效）
              
            

            
基础日志只记录连接、耗时和音频块数量；详细调试还记录标题、简介、背景、实际提示词、原文转写与译文片段。日志保存在本机扩展存储，不保存原始音频，并会遮盖已配置的 API Key；分享导出文件前仍请检查私人内容。进行中的日志最多落后约 2 秒。每场最多保留 3000 条事件，已结束日志最多保留最近 20 场。
