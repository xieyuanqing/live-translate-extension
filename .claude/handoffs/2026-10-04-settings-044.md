# 0.4.4：设置页整理与接口选用

日期：2026-10-04。用户授权完成全部修改，并在完成后提交 GitHub。承接未提交的 0.4.1／0.4.2 划词及播放器、0.4.3 接口入口改动；保留原有代码和私人日志。本版仍是开发版，没有创建商店或 GitHub Release。

## 已完成

- 九页分为开始、功能、外观与数据。新用户首次进入「接口」，记住已有访问位置并保留旧 hash 路由；手机用页面和接口下拉导航。
- 地址、Key、模型、授权只在「接口」配置；实时翻译、整片字幕、评论、划词在各自页面下拉选用。评论新增独立接口用途，旧配置首次沿用字幕接口后独立保存。聊天继续使用 Chrome 本地翻译，朗读用于划词原文和设置试听。
- 统一域名授权为一行状态及必要的授权按钮，详情折叠；千问「所有网站权限」明确显示。查询、生成测试、Gemini 试听在拒绝授权或授权期间换地址时不会发送请求。设置与后台共用不包含端口的 Chrome 主机权限模式，实际请求保留端口。
- 新用户顶部有配置指引；填写并授权与生成测试通过分开显示，修改地址、Key、模型等会使旧测试结果失效。切换编辑对象、复制接口不改变功能选用。
- 主题移至外观，字幕／评论／聊天样式在一页切换。字幕设置分组，宽屏预览吸顶。高级与关于收纳默认折叠的提示词、诊断日志和开发者命令；直播只默认展开选中的接口。
- 简化重复说明、卡片嵌套和列表内容，统一接口／模型／翻译偏好／聊天用词。保留接口恢复默认时，同时保留三类连接及四种文字接口用途。
- 版本、两份 README、CHANGELOG、开发说明同步 0.4.4。
