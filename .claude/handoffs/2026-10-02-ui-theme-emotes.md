## 实现

- `YouTubeText.readText` 忽略自定义图片表情的 alt 名称，只保留真正的 Unicode 图片表情。排除 `tp-yt-paper-tooltip`、`yt-tooltip-renderer`、`role=tooltip` 节点，以及脚本、样式和模板文字。正文与表情之间保留分隔，纯表情继续跳过。原图片与 YouTube 原生悬停提示不删除；其名称不再作为正文翻译，悬停也不改变原文或缓存身份。
- popup 根元素与 body 明确设为 420 px 宽，移除会在浏览器自动定宽期间自我约束的 `max-width:100vw`。标题和头部控件不换行。
- 新增仅用于 UI 的 `uiTheme`：跟随系统（默认）、浅色、深色。通用设置提供选择框，弹窗顶部有一键深浅切换；两页共用 `theme.js` 与本机设置。灰阶为背景 `#262626`、卡片 `#303030`、输入 `#383838`，搭配克制蓝色操作；控件、提示词、接口卡片和错误提示使用统一主题变量。网页译文样式预览保留独立深浅样本。
- 手选主题使用修订号与 pending 状态，避免初次读取或旧保存事件盖回最新选择。设置页保存排队串行，成功或失败恢复只接纳最后一次主题修订；失败恢复读存储期间的新选择也受保护。只读复查指出的两处竞态已修复并再次确认。
- 版本同步 manifest/package、README EN/ZH、CHANGELOG、开发说明；预览工具接入新增脚本。

## 使用与边界

在扩展管理页重新加载，关闭再打开弹窗，并刷新 YouTube 页面。「通用 → 界面外观」可选主题，弹窗右上角也能切换。

没有操作用户正在播放的真实 YouTube 页面，没有调用真实翻译模型或本地语言包。离线浏览器及模拟 DOM 验证不能证明 YouTube 当前 DOM、真实 Chrome action popup 和用户显示缩放下的最终行为；需更新后实图核对。此前直播、字幕接口、模型质量和日志耐久性待验证项仍保留；两阶段转写继续暂缓。
