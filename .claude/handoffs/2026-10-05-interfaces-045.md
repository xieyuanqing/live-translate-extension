# 0.4.5 接口预设、模型选择与自定义请求头

日期：2026-10-05。本次在减负重构 T1–T7 之后继续，分支仍为 `codex/trim-defensive`；前一份交接为 `2026-10-05-trim-defensive.md`。用户明确限定“先做预设与占位，本次完善模型选择和自定义请求头”，不接入新的直播、聊天或朗读客户端。继续遵循“不要过度防御性编程”。

## 已完成

- `LT.TEXT_PRESETS` 提供 Gemini、OpenAI、DeepSeek、硅基流动、方舟、百炼北京／新加坡、OpenRouter、Groq、月之暗面和自定义。只填协议与地址，新增独立配置，不覆盖凭据或功能选用。官方地址来源在 `docs/interface-presets.md`。
- 设置页模型改为自有可编辑组合框，右侧箭头显示全部模型，输入筛选，支持方向键、回车、Esc 与手填。获取失败或没有列表不妨碍手填；弹出列表按视口空间选择向上／向下。修改连接配置或切换编辑接口会取消并作废旧请求。
- `providers[].headers` 存储名称／值；名称归一化为小写，同名项覆盖默认头。设置页提供新增、移除、显示／隐藏值。实际发送前只校验 HTTP 名称和值的合法性。
- 模型列表、查询、生成、AI 整理、整片字幕、评论、划词共用请求头；直连和后台转发均携带，支持 API Key 留空、仅请求头鉴权。直播与朗读连接配置保持独立。
- 默认备份移除全部自定义请求头；无凭据备份导入时按配置 id 保留本机值。日志和划词错误沿用现有脱敏机制，把请求头纳入凭据处理。
- 新增“聊天翻译”接口说明标签；直播、聊天、专用 MT、TTS 的未来候选均折叠显示“暂未接入”，没有加入可运行提供者列表。
- 版本同步为 0.4.5，双 README、CHANGELOG、开发文档已更新。上一轮 T1–T7 的记录并入 0.4.5。
