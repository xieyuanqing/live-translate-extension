## 改动

- 参考本地 Read Frog 的 `config-item.tsx` / `config-section.tsx` / popup 页面结构，KISS 的公开设置入口与样式预览源代码、沉浸式翻译的官方面板/设置使用文档。实现是本仓库自己的普通 HTML/CSS/JS。
- `src/ui/ui.css` 统一浅色主题：浅灰底、白色圆角卡片、蓝色操作、清晰的红色错误状态、系统字体与原生控件。功能 checkbox 画成 iOS 式绿色开关，保留原生键盘和 checked 行为；系统深色模式下 UI 仍为浅色。
- `options.css/html` 重新整理侧栏分组、图标和选中状态，统一语言字段、接口配置卡片、预设卡、分段控件、提示词、日志、缓存及字幕预览。窄屏保留可横向滚动的分区导航。文字样式默认预览浅色网页，可主动查看深色网页样本；这不是扩展界面的主题开关。
- `popup.css/html` 与设置页对齐。语言选择放在主操作前；聊天/评论使用独立滑动开关，模型说明另起小字；可展开的本场提示词/术语移动到常用聊天评论操作后。`popup.js` 的状态/音量区只在会话非 idle 时展示，减少未开始时的空区域，并使用适合浅色界面的错误颜色。
- 原有 12 种译文样式、过滤规则、API/缓存/会话逻辑未改变。没有把 UI 浅色主题注入 YouTube 内容脚本，真实网页和播放器继续按原来的样式显示。
- 版本同步 manifest/package、README EN/ZH、CHANGELOG 与开发文档。预览版本动态读取 manifest。
